# Brief produk

## Masalah
UMKM dan individu ingin chatbot WhatsApp otomatis yang terasa natural (bukan menu kaku "ketik 1 untuk..."), tapi:
- Bikin sendiri butuh skill coding + biaya API bulanan yang bikin ragu
- Solusi SaaS di luar sana biasanya berlangganan bulanan

## Solusi
Produk sekali beli (source code atau installer `.exe`) yang:
- User pasang sendiri (PC/laptop 24 jam GRATIS, atau VPS berbayar mandiri)
- User pakai API key sendiri (Gemini/Grok) — bayar sesuai pemakaian, bukan langganan ke kita
- Dikonfigurasi lewat web dashboard, tanpa edit kode

## Target user
1. Pemilik UMKM kecil (toko online, kedai, jasa) — butuh Mode Bisnis
2. Individu yang mau asisten pencatatan keuangan pribadi — butuh Mode Personal
3. Reseller/jasa digital — beli lisensi white-label, jual ulang ke klien

## Dua mode utama
- **Mode Bisnis** — cek stok, kirim gambar produk, rekomendasi, human handover kalau bot ragu
- **Mode Personal** — catat pengeluaran dari kalimat bebas, rekap otomatis, reminder

## Model distribusi (dijual di Lynk.id)
- Paket Basic — source code + ebook panduan instalasi
- Paket Pro — installer `.exe` siap pakai
- Paket Reseller — lisensi white-label, boleh dijual ulang

## Batasan yang wajib disclose ke buyer
- whatsapp-web.js adalah automation tidak resmi — ada risiko nomor kena banned WhatsApp kalau disalahgunakan (broadcast massal, spam)
- Bot butuh device (PC/VPS) menyala terus-menerus supaya online 24 jam
